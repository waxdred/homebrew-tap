# waxdred/tap

Homebrew formulae of [waxdred](https://github.com/waxdred).

```sh
brew install waxdred/tap/skyland
skyland install
```

| Formula | |
|---|---|
| `skyland` | [Hyprland-like tiling window manager for macOS](https://github.com/waxdred/skyland) |
| `skylandbar` | [Status bar in Liquid Glass, the bar of skyland, SketchyBar compatible](https://github.com/waxdred/skylandBar) |
| `skyland-cyberdeck` | [Cyberpunk apps launcher, messages panel and notify API](https://github.com/waxdred/skyland-cyberdeck) |
